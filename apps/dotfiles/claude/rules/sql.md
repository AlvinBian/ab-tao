## 註釋分層（強制）

- **區段分隔**：主結構（CTE / SELECT / JOIN / WHERE / ORDER BY）以 `-- ========== N. 區段名 ==========` 開頭，N 為阿拉伯數字序號。
- **層級序號**：區段內分組 / 欄位用 `N.M`，再細用 `N.M.K`（如 `1`、`1.1`、`1.1.1`）；序號連續、不跳號，跨區段重編。
- **檔頭 block 不重複文件 section 號**（如 `8.7`）；section 號交給文件標題層級，不在 SQL 內重複。
- 註釋只描述 **SQL 與資料本身**（欄位語義 + 技術理由），**不寫業務 / 專案脈絡**（下游用途如「供 X 判決」、專案狀態如「Phase 1 旁路」「進線率 0.01%」、跨頁一致性如「與全頁統一」）。
- 欄位註釋說明欄位語義，不覆述欄位名；冗餘者寧可不寫。

## 排版（強制）

- 行尾註釋**緊跟**欄位 / 運算式後，用**兩格空白**分隔：`欄位,  -- N.M 說明`。
- **禁止對齊填充**：不得為了讓多行 `--` 視覺對齊而插入大量空白。
- **禁止多餘空行**：分組靠 `-- N. 分組名` 區隔，不留空行；僅大區段間（`==========`）可視需要換行。
- 可選檔頭 block：頂部用 `-- ===` 框 1–3 行，純描述「這條 SQL 抓什麼 + 結構陷阱」，不放業務脈絡與 section 號。

## 理由內聯

- 非顯而易見的技術選擇（特殊 JOIN 條件、QUALIFY 去重、CAST、UNNEST、過濾）必須附**為什麼**，接在說明同一行。

## 查詢品質與成本意識

- 表名一律帶**完整 project / dataset 前綴**，確保複製即可跑。
- 標明資料物件型態：**VIEW**（時間條件常無法剪枝，省成本靠減少選取欄位、勿 `SELECT *`）vs **PARTITION 表**（過濾欄位直接字面比較才觸發剪枝，勿用 `DATE()` 包裹 partition 欄位）。
- JOIN 一對多會發散時用 `QUALIFY ROW_NUMBER() OVER(...)` 或子查詢去重，註明去重鍵與排序依據。
- 時間窗、列數上限等限制覆蓋範圍的條件須在註釋明示。
- 敏感欄位（PII：email / 電話…）標記敏感等級，呼應 `~/.claude/claude-md/05-security.md`：禁 log、前端遮罩。

## 風格

- 繁體中文註釋；SQL 關鍵字、表名、欄位名保留原文。
- 欄位按職責用分組標題（如 追溯主鍵 / 內容欄位 / 關聯鍵 / 快照），每組一個 `-- N. 分組名`。
