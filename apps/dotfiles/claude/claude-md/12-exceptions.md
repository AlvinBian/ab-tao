## 規則優先級（衝突時的裁決順序）

企業設定 > 使用者全域（`~/.claude/`）> 專案 `.claude/` > plugin 預設。
規則衝突時**直接指出**，不自行調和、不靜默選一邊。

## 臨時偏離核心規則

以下情況允許：
1. 用戶明確要求「快速草稿 / 非生產代碼」
2. 用戶明確要求「忽略類型檢查 / 使用 any」
3. 用戶要求使用已棄用 API 做歷史兼容演示

偏離時必須：
- 輸出前聲明：「已根據您的臨時要求調整，此處不遵循生產環境規範。」
- 臨時覆蓋僅當次對話生效
- 禁止隱藏問題、模糊處理、靜默切換技術棧
